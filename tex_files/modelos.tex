\section{Modelado de Regresión}
    \begin{frame}[fragile]{Regresión lineal}
        Si se tiene un vector de datos observables \textit{x} y uno de variables respuestas \textit{y}, entonces
        \begin{verbatim}
            y ~ x
            y ~ 0 + x
        \end{verbatim}
        Definen un modelo lineal simple, el primero con interessción y el segundo sin. Si se busca 
        obtener la logarítmica, entonces
        \begin{verbatim}
            log(y) ~ x
        \end{verbatim}
    \end{frame}

    \begin{frame}[fragile]{Otras regresiones}
        Para regresiones multivariadas, el operador + añade variables predictoras a la construcción de un modelo
        \begin{verbatim}
            y ~ x_1 + x_2 + ... + x_n
        \end{verbatim}
        Para regresiones curvas, podemos definir un modelo polinomial con
        \begin{verbatim}
            y ~ poly(x, grado)
        \end{verbatim}
        %Aquí valdría mencionar que se pueden mezclar ambos enfoques pero hay que construir una matriz X
        %La notación para esto es y ~ X + poly(x, grado)
    \end{frame}

\section{Modelos de anova}
    \begin{frame}[fragile]{Modelos para ANOVA}
        El consenso práctico es tener una dataframe \textit{df} con la variable respuesta como dato númerico
        y los tratamientos como variables de tipo factor. Las columnas de variables factor, pueden ser 
        entendidas como tratamientos u efectos de bloqueo.
        \begin{verbatim}
            df$respuesta ~ df$tratamiento
        \end{verbatim}
        La primer columna es el tramiento, se pueden añadir efectos de bloqueo con el operador +
        \begin{verbatim}
            df$respuesta ~ df$trat + df$bloq1 + ... + df$bloq2
        \end{verbatim}
    \end{frame}

    \begin{frame}[fragile]{Modelos para ANOVA}
    El operador * sirve para añadir tratamientos. Primero deben ir los * y después los +
    \begin{verbatim}
            df$respuesta ~ df$trat1 * df$trat2
        \end{verbatim}
    \end{frame}
